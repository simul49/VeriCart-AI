# 25. Glossary

# 25.1 Introduction

This glossary defines the key technical, business, software engineering, Artificial Intelligence, security, database, DevOps, and e-commerce terms used throughout the VeriCart AI Product Requirements Document.

The purpose of this glossary is to ensure consistent understanding among developers, instructors, project stakeholders, and future contributors.

---

# 25.2 General Software Engineering Terms

## Agile

An iterative software development methodology that delivers software through short development cycles called sprints.

---

## API (Application Programming Interface)

A set of rules and endpoints that enables different software applications to communicate with each other.

---

## Architecture

The high-level structure of a software system, including its components and interactions.

---

## Backend

The server-side application responsible for business logic, data processing, authentication, and communication with databases and AI services.

---

## Bug

A defect or error that causes software to behave unexpectedly.

---

## CI/CD

Continuous Integration and Continuous Deployment, a practice for automating software building, testing, and deployment.

---

## CRUD

The four basic database operations:

- Create
- Read
- Update
- Delete

---

## Deployment

The process of making software available to users in a target environment.

---

## Frontend

The client-side application that users interact with through a web browser.

---

## Functional Requirement

A feature or capability that the system must provide.

---

## Non-Functional Requirement (NFR)

A quality attribute describing how well the system performs, such as security, scalability, or performance.

---

## MVP (Minimum Viable Product)

The smallest version of a product that delivers core value while allowing future enhancements.

---

## PRD (Product Requirements Document)

A comprehensive document describing product goals, requirements, architecture, user experience, and implementation guidance.

---

## REST API

An architectural style for building web services using HTTP methods such as GET, POST, PUT, and DELETE.

---

## Sprint

A fixed development period in Agile Scrum during which a set of features is implemented.

---

# 25.3 Artificial Intelligence Terms

## Artificial Intelligence (AI)

Computer systems capable of performing tasks that typically require human intelligence, including language understanding and reasoning.

---

## Large Language Model (LLM)

A machine learning model trained on large text datasets to understand and generate natural language.

Examples used in VeriCart AI:

- DeepSeek
- Kimi
- Tencent Hunyuan

---

## AI Gateway

A dedicated service responsible for routing AI requests, managing prompts, aggregating responses, and handling communication with multiple LLM providers.

---

## Prompt

The instruction or input sent to a Large Language Model.

---

## Prompt Engineering

The practice of designing prompts to produce reliable, accurate, and useful AI responses.

---

## Sentiment Analysis

The process of identifying the emotional tone of text, commonly classified as Positive, Neutral, or Negative.

---

## Fake Review Detection

The AI process of identifying reviews that appear suspicious, repetitive, or manipulated.

---

## Trust Score

An AI-generated score (0–100) indicating the estimated reliability of a product based on customer reviews and analysis.

---

## AI Confidence Score

A value representing the AI model's confidence in its prediction or recommendation.

---

## Explainable AI (XAI)

AI techniques that provide understandable reasons for predictions or recommendations.

---

## Multi-LLM Architecture

An AI architecture that combines multiple Large Language Models, assigning different responsibilities to each model.

---

## AI Hallucination

A situation where an AI model generates information that is incorrect, fabricated, or unsupported by available evidence.

---

## Retrieval-Augmented Generation (RAG)

An AI architecture that combines external knowledge retrieval with language model generation to improve factual accuracy.

---

## Embedding

A numerical representation of text or other data used for semantic search and machine learning.

---

## Vector Database

A database optimized for storing and searching embeddings used in semantic retrieval systems.

---

# 25.4 Security Terms

## Authentication

The process of verifying a user's identity.

---

## Authorization

The process of determining what resources an authenticated user is allowed to access.

---

## JWT (JSON Web Token)

A secure token used for stateless authentication between frontend and backend services.

---

## RBAC (Role-Based Access Control)

An authorization model that grants permissions according to user roles.

---

## BCrypt

A secure password hashing algorithm used for password storage.

---

## HTTPS

A secure communication protocol that encrypts data transmitted over the internet.

---

## SQL Injection

A security attack that attempts to execute malicious SQL statements through application inputs.

---

## Cross-Site Scripting (XSS)

A web vulnerability where malicious scripts are injected into web pages viewed by users.

---

## CORS (Cross-Origin Resource Sharing)

A browser security mechanism that controls which origins are permitted to access web resources.

---

## OWASP

The Open Worldwide Application Security Project, which publishes widely adopted web application security guidelines.

---

# 25.5 Database Terms

## Database

An organized collection of structured data.

---

## MySQL

The relational database management system used by VeriCart AI.

---

## MyBatis

A persistence framework that maps Java objects to SQL statements.

---

## Entity

A database object representing a real-world concept, such as User or Product.

---

## ER Diagram (Entity Relationship Diagram)

A diagram illustrating entities and their relationships within a database.

---

## Primary Key

A unique identifier for each record in a table.

---

## Foreign Key

A field that establishes a relationship between two database tables.

---

## Transaction

A sequence of database operations executed as a single unit of work.

---

## Normalization

The process of organizing database tables to reduce redundancy and improve integrity.

---

# 25.6 DevOps Terms

## Docker

A containerization platform that packages applications and their dependencies into portable containers.

---

## Docker Compose

A tool for defining and managing multi-container Docker applications.

---

## Container

An isolated runtime environment that packages software together with its dependencies.

---

## Nginx

A high-performance web server commonly used as a reverse proxy and load balancer.

---

## Environment Variable

A configuration value supplied outside the application source code.

---

## Reverse Proxy

A server that forwards client requests to backend services.

---

## Health Check

An automated mechanism used to verify whether an application or service is functioning correctly.

---

# 25.7 E-commerce Terms

## Shopping Cart

A temporary collection of products selected by a customer before checkout.

---

## Checkout

The process of confirming an order and providing shipping details.

---

## Wishlist

A list of products saved by users for future consideration.

---

## Product Review

Feedback submitted by customers regarding their purchasing experience.

---

## Product Recommendation

Products suggested to users based on AI analysis or recommendation algorithms.

---

## Order Status

The current stage of an order.

Typical statuses include:

- Pending
- Paid
- Processing
- Shipped
- Delivered
- Cancelled

---

## Customer Journey

The complete sequence of interactions between a customer and the platform, from product discovery to post-purchase review.
