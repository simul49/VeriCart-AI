# 8. Project Scope

## 8.1 Introduction

A clearly defined project scope is essential for ensuring successful software development. It establishes the boundaries of the project, defines what will and will not be implemented, and ensures that all stakeholders share a common understanding of the project's objectives.

For the Mini Semester Project, VeriCart AI aims to deliver a **Minimum Viable Product (MVP)** that demonstrates modern full-stack software engineering combined with practical Artificial Intelligence applications.

Rather than attempting to compete with commercial platforms such as Amazon or Alibaba, VeriCart AI focuses on solving one specific challenge:

> **Helping customers make trustworthy purchasing decisions through AI-powered review intelligence.**

The scope is intentionally designed to balance innovation with feasibility within the available development timeline.

---

# 8.2 Project Objectives Within Scope

The project will focus on developing an intelligent e-commerce platform that provides:

- Secure user authentication
- Product browsing and searching
- Shopping cart management
- Order management
- Customer review system
- AI-powered review analysis
- AI-generated Trust Score
- AI review summarization
- Fake review detection
- Personalized product recommendations
- Intelligent shopping assistant
- Responsive web interface
- RESTful backend services

- Manage categories

- Sentiment Analysis

# 8.14 Success Criteria

Version 1.0 will be considered successful if:

- All functional modules operate correctly.
- Frontend and backend communicate successfully.
- AI analyzes reviews accurately.
- Trust Scores are generated automatically.
- Product recommendations function correctly.
- The application is securely deployed using Docker.
- Users can complete the shopping process from registration to order placement.

---

# 8.15 Chapter Summary

The project scope defines the boundaries of VeriCart AI by identifying the features, technologies, and AI capabilities that will be implemented during the Mini Semester Project.

The MVP focuses on delivering a complete AI-powered e-commerce platform that integrates secure software engineering practices with practical applications of Artificial Intelligence.

Features outside the scope are intentionally deferred to future releases, ensuring that Version 1.0 remains achievable while establishing a scalable foundation for future development.
