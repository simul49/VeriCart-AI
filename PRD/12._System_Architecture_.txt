# 13. System Architecture
---
# 13.1 Introduction
The VeriCart AI system follows a modern frontend-backend separation architecture that combines Vue.js 3, Spring Boot, MyBatis, MySQL, Docker, and multiple Large Language Models (LLMs).
The architecture is designed around four major principles:
- Separation of Concerns
- Scalability
- Security
- AI Extensibility
Instead of embedding AI directly inside the backend, VeriCart AI introduces an independent AI Integration Layer that communicates with multiple LLM providers through secure REST APIs.
This design allows the platform to integrate future AI models without changing the core business logic.

# 13.3 Architectural Principles
The architecture follows several important software engineering principles.
---
## Separation of Concerns
Each layer has a single responsibility.
Presentation Layer
↓
Business Layer
↓
Data Access Layer
↓
Database
---
## Loose Coupling
Every module communicates through interfaces rather than direct implementation.
Benefits
- Easy maintenance
- Better testing
- Higher scalability
---
## High Cohesion
Each module performs one clearly defined responsibility.
Example
Authentication Module
↓
Only authentication.
AI Module
↓
Only AI processing.
---
## Dependency Injection
Spring Boot Dependency Injection manages service relationships.
Advantages
- Reduced coupling
- Better testing
- Cleaner code

# 13.18 Chapter Summary
VeriCart AI adopts a modern layered software architecture that separates presentation, business logic, data access, and Artificial Intelligence into independent modules.
The architecture enables secure, scalable, and maintainable software development while supporting future AI expansion.
The introduction of a dedicated AI Gateway allows DeepSeek, Kimi, and Tencent Hunyuan to collaborate efficiently without tightly coupling AI services to business logic.
This architecture establishes the technical foundation for the remaining chapters, including Database Design, API Specification, AI Architecture, Deployment, and Software Testing.
